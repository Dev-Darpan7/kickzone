# 👟 KickZone

KickZone is a responsive e-commerce website for sneaker and shoe enthusiasts, built using **PHP, MySQL, JavaScript, HTML, and CSS**. It allows users to browse footwear, manage their cart, place orders, and securely manage their accounts through a clean and user-friendly interface.

---

## ✨ Features

### 👤 User Authentication

* User registration and login
* Logout functionality
* Forgot password
* Change password
* Profile management

### 👟 Shopping Experience

* Browse shoe collection
* Product details page
* Add and remove products from cart
* Shopping cart management
* Secure checkout process

### 💳 Order & Payment

* Place orders
* Payment integration
* Payment success page
* Order confirmation
* View order history
* Cancel orders

### 🛠️ Admin Panel

* Manage products
* Manage customer orders
* View user information

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Dev-Darpan7/kickzone.git
```

### Move the project

Copy the project folder into your XAMPP `htdocs` directory.

```
C:\xampp\htdocs\kickzone
```

### Import the database

1. Start **Apache** and **MySQL** in XAMPP.
2. Open **phpMyAdmin**.
3. Create a database named `kickzone`.
4. Import the `kickzone.sql` file.

### Configure the database

Update your database credentials in `db.php` if required.

### Run the project

Open:

```
http://localhost/kickzone
```
